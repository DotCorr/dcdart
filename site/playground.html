Supported code and execution limits

Write a single DCDart file using @bare functions. Callable entry points accept and return u64 or f64. The prelude is included automatically; file imports and packages are unavailable. This is DCDart’s supported language subset, not the general Dart or Flutter runtime.

Compilation runs in an isolated, temporary container: 32 KiB of source, a 40-second compile limit, and six requests per minute. Execution uses fresh browser WebAssembly memory, a two-second limit, and a 16 MiB memory cap. Compilation errors and unsupported features are reported as errors. Source is kept on this device and sent to the compiler when you press Run.
